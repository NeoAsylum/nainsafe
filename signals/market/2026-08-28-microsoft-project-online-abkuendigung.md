# Microsoft stellt Project Online zum 30.9.2026 ein

Microsoft beendet die cloudbasierte Projektportfolio-Plattform Project Online endgueltig zum 30.9.2026. Bereits seit 1.10.2025 koennen keine neuen Lizenzen mehr gekauft werden, ab 1.4.2026 lassen sich keine neuen Project-Web-App-Sites mehr anlegen, und ab 2.4.2026 funktionieren SharePoint-2013-Workflows darin nicht mehr. Nach dem Stichtag ist der Zugriff auf Projekte und Daten nicht mehr moeglich; Microsoft verweist Bestandskunden auf Project Server Subscription Edition, Planner Premium oder Dynamics 365 Project Operations.

## Belegstelle

"Offizieller Stichtag: 30. September 2026" mit vorgelagerten Meilensteinen (Verkaufsstopp 1.10.2025, Site-Erstellungsstopp 1.4.2026, Workflow-Abschaltung 2.4.2026) — so uebereinstimmend berichtet von mehreren unabhaengigen PPM-Fachportalen (epicflow.com, celoxis.com, inetum.com, holert.com), die sich auf Microsofts veroeffentlichten Ruhestandszeitplan und einen Blogbeitrag im Microsoft Community Hub (techcommunity.microsoft.com) beziehen. Der Originaltext des Microsoft-Blogbeitrags selbst liess sich beim Abruf technisch nicht laden.

## Was unklar ist

Die Migration auf die genannten Nachfolgeprodukte (Project Server SE, Planner Premium, Dynamics 365 Project Operations) ist kein automatischer Umzug, sondern erfordert je nach Produkt neue Lizenzierung, eigene Infrastruktur (Project Server SE) oder funktionale Abstriche (Planner). Ob es fuer die vorhandene mehrjaehrige Projekt- und Ressourcenhistorie ein verlustfreies Migrationswerkzeug gibt, geht aus den Sekundaerquellen nicht eindeutig hervor. Kein unabhaengiger Drittanbieter positioniert sich bislang oeffentlich als direkter Ersatz fuer deutsche PMOs.
